# ACHD-related Arrhythmias

![[ACHD Basics-1754796788998.webp]]
Figure [source](https://www.researchgate.net/figure/Schematic-of-factors-leading-to-arrhythmias-in-A-pre-and-B-postoperative-congenital_fig1_363157018)

| Congenital Heart Condition                | Arrhythmia                                                                                |
| ----------------------------------------- | ----------------------------------------------------------------------------------------- |
| Repaired sinus venosus defect             | [[Sinus Node Dysfunction (SND)]]                                                          |
| Ebstein anomaly                           | [[Accessory Pathway Conduction\|Accessory pathway]], [[Atrial Fibrillation (AFib)\|AFib]] |
| Atrioventricular canal defect             | Complete heart block, IART                                                                |
| Tetralogy of Fallot                       | IART, [[Ventricular Tachycardia (VT)\|VT]], [[Sudden Cardiac Death (SCD)\|SCD]]           |
| Transposition (D-loop TGA), atrial switch | [[Sinus Node Dysfunction (SND)]], IART                                                    |
| Congenitally corrected TGA (L-loop TGA)   | Complete heart block                                                                      |
| Single ventricle (Fontan)                 | [[Sinus Node Dysfunction (SND)]], IART, [[Atrial Fibrillation (AFib)\|AFib]]              |
| Eisenmenger syndrome                      | IART, Sudden death                                                                        |
